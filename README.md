# Core Banking, without the big-bang rewrite

An independent interview artifact for an Avarda Core Banking Product role. It clarifies the candidate’s experience boundary, then demonstrates product depth through financial-state ownership, payment/accounting controls, migration equivalence and vendor-core product management.

## Run locally

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm test
npm run build
npm run screenshots
```

The screenshot check captures full-page renders at 1440 px, 768 px and 390 px. Evidence discipline and candidate-claim wording are recorded in `docs/EVIDENCE_LEDGER.md`.

## Evidence policy

The artifact distinguishes public facts, reasoned inferences and items that require internal validation. It does not claim direct end-to-end Corniche administration or any unverified connection involving HSBC, Wells Fargo or a specific candidate data stream.
